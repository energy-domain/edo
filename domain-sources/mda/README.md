# MDA

This directory contains source material from the MDA (Master Data Attributes) survey used as a domain reference in the development and curation of the EDO.

## Status and scope

The MDA is not an authoritative standard or a normative specification for the EDO. It is an information survey produced within Petrobras, based on the subsea area and originally intended for information organization.

The MDA has served as an important source of classes and properties for the EDO. Its content should therefore be treated as domain source material: evidence and input for ontology development, not as a specification that the EDO or other artifacts are required to conform to.

The presence of material in this directory does not, by itself, imply normative authority, completeness across the energy domain, or applicability beyond its original scope.

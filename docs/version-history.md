## Flexible v3.0.4 — Legacy Branch

The branch `legacy/flexible-v3.0.4` was originally created during
the initial development process using the version number `v3.0.4`.

The version numbering was subsequently corrected to `v2.2`.

This branch is preserved exclusively for historical traceability and
does not represent an official released version of the Energy Domain
Ontology.
